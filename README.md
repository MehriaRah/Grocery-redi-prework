# 🛒 Grocery Bud

A simple, interactive, and modern web application to help you keep track of your grocery items. Built with **Vanilla JavaScript**, **HTML5**, and **CSS3**, featuring **Local Storage** persistence for seamless everyday use.

![Grocery Bud App](https://img.shields.io/badge/JavaScript-ES6-yellow.svg) ![HTML5](https://img.shields.io/badge/HTML-5-orange.svg) ![CSS3](https://img.shields.io/badge/CSS-3-blue.svg)

---

## 🚀 Features

- **➕ Add Items**: Add new grocery items to your list quickly with validation to prevent empty submissions.
- **✏️ Edit Items**: Click the edit icon on any item to update its text.
- **🗑️ Delete Single Item**: Remove individual items from your list using the trash icon.
- **🧹 Clear All Items**: Wipe the entire grocery list with a single click.
- **🔔 Dynamic Alerts**: Visual feedback for every action (adding, editing, removing, or empty inputs).
- **💾 Local Storage Persistence**: Your grocery list is saved directly in your browser, keeping your list intact when you reload or close the tab.
- **📱 Responsive Layout**: Modern card-style UI designed to look great on desktop and mobile screens.

---

## 🛠️ Built With

* **HTML5**: Semantic document structure.
* **CSS3**: Custom styles, responsive flexbox layout, and CSS variables.
* **JavaScript (ES6)**: DOM manipulation, event handling, and Local Storage management.
* **Font Awesome**: Clean icons for edit and delete actions.
